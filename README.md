# Conversación I — 스페인어 회화 I 학습 사이트

고등학교 스페인어 회화 I(전라남도교육청) 12개 과를 학생들이 브라우저에서 바로 풀 수 있도록 만든 정적 학습 사이트입니다. 다인에듀 수업용.

## 구성
- `index.html` 메인 페이지(12개 과 목록, 전체 점수)
- `lessons/01.html … 12.html` 각 과(대화문 · 연습문제 · ¡Compruébalo! · Expresiones útiles)
- `resources.html` 음원 자료실(제공받은 mp3 80개)
- `data/lessonNN.js` 각 과의 내용·정답 데이터, `assets/` 스타일·스크립트, `audio/` mp3

## 사용 방법
- 서버가 필요 없습니다. GitHub Pages에 올리면 바로 동작합니다.
- 채점 결과와 입력한 이름은 학생 기기 브라우저(localStorage)에만 저장됩니다.
- 듣기 문제는 교재 뒤쪽 대본(Transcripciones)을 미리 만들어 둔 스페인어 신경망 음성(Piper es_ES, 남·여 2명, `tts/`)으로 들려줍니다. 대화문은 화자별로 목소리가 다릅니다. 새 문장을 추가하면 브라우저 기본 음성으로 대신 읽습니다.

## 점수 방식
- 교재 해답(Soluciones)이 있는 문제만 자동 채점합니다. 해답이 없는 보충 문제는 문제 제목 아래에 표시했습니다.
- 말하기·쓰기 활동은 채점하지 않고 「연습했어요」 체크와 예시 답안만 제공합니다.
- 철자는 대소문자·문장부호를 무시하며, 악센트만 틀리면 점수는 인정하고 안내 문구를 보여 줍니다.

## 올바른 음원을 연결하려면
제공된 mp3는 현재 교재가 아닌 「2022 개정」 교재의 음원이라 자동 연결하지 않았습니다. 올바른 파일이 있다면 `audio/`에 넣고 `data/audio-map.js`에 `"과번호.활동id": "경로"` 형태로 적으면 해당 듣기 문제에서 mp3가 재생됩니다. (예: `"1.a3": "audio/L01_a3.mp3"`)
